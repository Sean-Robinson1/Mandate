Valio Aimo Junction 2026 Challenge

General

Challenge material consists of:

  1. Pricing API that can be queried to find prices for products
  2. Availability API that can be queried to determine if a product is available for requested delivery date
  3. Product data file that has general product information and product codes that can be used with API calls and other files
  4. JSON schema to explain product data file
  5. Delivery reliability data file
  6. Carbon footprint data file

Data

Product data

Product data usually originates from maker of the product and quantity / quality of data varies: for example factory-made meals with a GTIN code will typically contain precise nutritional and allergen information but fruits and vegetables are often lacking such information.

While inspired by real world, this dataset does not contain fully accurate product information and it must not be used for anything outside of this challenge.

  • Download product dataFull product data set as JSON
  • Download product data schemaJSON Schema describing the product data file

Delivery reliability

This file tells how reliably a product has historically been delivered compared to ordered quantities. It is given as a value between 0 and 1, where 1 means that all orders were delivered as ordered.

Products are identified with the same product codes as in the product data. Not every product has a value.

  • Download delivery reliabilityDelivery reliability per product as CSV

Carbon footprint

Estimated average carbon footprint per kilogram of product, in the column AVG kg CO2-eq/kg. The value is an average for the product group the product belongs to, not a measurement of the individual product.

Products are identified with the same product codes as in the product data. Not every product has a value.

  • Download carbon footprintCarbon footprint per product as CSV

Authentication

Everything under /api requires an X-API-Key header. API key can be found on the Junction platform

curl -H "X-API-Key: <api key from platform>" https://junction26.valioaimo.fi/api/ping
